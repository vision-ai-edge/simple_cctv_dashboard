# Simple CCTV Dashboard - 제품 문서

## 비전 및 목표

### 미션

CCTV 카메라를 실제 지도 위에 배치하고, EdgeAI Box API를 통해 통합 관리하며 실시간 모니터링할 수 있는 웹 대시보드를 제공합니다. 시설 관리자가 다중 박스 확장 준비가 되어있는 단일 인터페이스에서 모든 카메라를 제어하고 모니터할 수 있도록 합니다.

### 비전

현장 기반 영상 분석 인프라(EdgeAI Box)를 효율적으로 활용하여 중앙집중식 모니터링을 실현합니다. 복잡한 CCTV 관리를 단순화하면서도 확장성 있는 아키텍처를 갖춥니다.

### 해결하는 문제

1. **분산된 카메라 관리**: 여러 물리적 위치의 카메라를 하나의 대시보드에서 한눈에 파악할 수 없음
2. **지도 기반 위치파악 부재**: 카메라 설치 위치를 맥락(지도)으로 이해하기 어려움
3. **실시간 알림 부재**: AI 검출 이벤트 발생 시 즉시 알림을 받을 수 없음
4. **매번 상담 필요**: EdgeAI Box API 통합 시 매번 커스텀 개발 필요

## 핵심 사용자 페르소나

### 시설 관제 운영자 (PRIMARY)

- **역할**: 하루종일 대시보드에서 카메라 모니터링, 알림 대응
- **능력**: 기본적인 웹 UI 조작, 디바이스 관리 이해
- **목표**: 
  - 모든 카메라 상태를 한눈에 보기
  - 지도에서 카메라 물리적 위치 파악
  - 침입/이상탐지 이벤트 즉시 알림받기
  - 카메라별 실시간 영상 스트리밍 확인
  - 녹화, 스냅샷, 타임랩스 저장

## MVP 핵심 기능 8가지

### 1. 지도 기반 카메라 배치
- **설명**: 오픈스트리트맵(OSM) 위에 CCTV 마커 표시
- **목표**: 1초 이내 마커 렌더링
- **범위**: 현재 Box의 모든 카메라 표시, Pan-Zoom 지원

### 2. 라이브 영상 스트리밍
- **설명**: HLS 또는 WebRTC를 통한 실시간 영상 재생
- **목표**: 지연시간 1초 이내
- **범위**: 단일 카메라 라이브 보기, 재생/중지 컨트롤

### 3. 녹화 및 스냅샷
- **설명**: 라이브 영상의 특정 구간 저장 또는 프레임 캡처
- **범위**: 브라우저에서 로컬 다운로드

### 4. 타임랩스 생성
- **설명**: 시간범위 지정하여 빠른 재생 영상 생성
- **범위**: 선택한 카메라의 시간대별 요약 보기

### 5. AI 검출 이벤트 알림 (토스트 + WebPush + Telegram)
- **설명**: 카메라별 AI 검출(침입, 넘어짐 등) 이벤트 실시간 감지 및 알림
- **목표**: 이벤트 발생 후 5초 내 알림 전달
- **채널**:
  - In-dashboard 토스트 알림 (Hono SSE)
  - 브라우저 WebPush (백그라운드)
  - Telegram Bot (외부 연락처용)
- **범위**: 다중 알림 채널 동시 지원

### 6. 다중 Box 확장 준비 (스키마 레벨)
- **설명**: 데이터 모델에서 `box_id` 컬럼 포함하여 MVP 실행 후 확장 용이
- **범위**: 인증, 채널 동기화, UI 흐름 모두 box-aware 설계

### 7. Box 등록 & 채널 동기화 — 등록 부분 구현 완료 (SPEC-BOX-001)
- **설명**: EdgeAI Box URL, 자격증명 입력 후 채널 자동 동기화
- **범위**: 최초 1회 등록, 주기적 갱신 워커
- **구현 상태**: Box 등록·자격증명 볼트(AES-GCM)·헬스체크·60초 상태 폴링 완료. 채널 동기화는 후속 SPEC-BOX-002로 분리.

### 8. 사용자 인증 (로그인/로그아웃) — 구현 완료 (SPEC-AUTH-001)
- **설명**: JWT HttpOnly 쿠키 기반 인증 시스템
- **범위**: 
  - `/login` 페이지 (사용자명/비밀번호)
  - JWT 토큰 발급 (Access 15분, Refresh 7일)
  - 보호 라우트 가드 (`/(app)` 레이아웃에서 세션 검증)
  - `/logout` 토큰 폐기 (블랙리스트 등록)
  - 타이밍 안전 비밀번호 비교 (bcryptjs)
  - Refresh 로테이션 + 재사용 감지 (jti 블랙리스트)
  - 레이트 리미팅 (`POST /api/auth/login` 15분 5회)

## 명시적 비목표

- **멀티테넌트 SaaS**: 단일 팀/조직 운영 모델만 지원
- **네이티브 모바일 앱**: 웹 브라우저 기반만 제공 (반응형 모바일 웹)
- **자체 영상 처리**: EdgeAI Box의 검출 모델만 활용, 자체 AI 개발 안함

## 성공 지표

| 지표 | 목표 | 측정 방법 |
|------|------|---------|
| **지도 마커 표시 시간** | 1초 이내 | 네트워크 부하 테스트, 카메라 50개 기준 |
| **라이브 영상 지연** | WebRTC: 1초 이내 | 스트리밍 품질 검증 |
| **검출 이벤트 알림 시간** | 5초 이내 | EdgeAI Box → 대시보드 → 사용자 전달 시간 측정 |
| **시스템 가용성** | 99.5% | 월간 다운타임 추적 |
| **UI 반응성** | 100ms 이내 | 버튼 클릭 → 화면 업데이트 |

## 기술 스택 개요

| 계층 | 기술 |
|------|------|
| **프론트엔드** | SvelteKit + TypeScript + TailwindCSS + shadcn-svelte |
| **지도** | Leaflet + OpenStreetMap |
| **영상 재생** | hls.js |
| **백엔드** | Bun + Hono + Zod |
| **데이터베이스** | SQLite (bun:sqlite) + Drizzle ORM |
| **인증** | JWT (jose), bcrypt |
| **실시간 알림** | Hono SSE, Web Push API, Telegram Bot API |
| **외부 연동** | EdgeAI Box REST API |
